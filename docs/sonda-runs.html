Sonda das runs

Versão 2: anota todos os pedidos da página (também os do Fast Break antigo, por GraphQL) logo desde o início, sem esperar por nada. Apaga o favorito antigo e põe este.

Serve para eu ver como o Top Shot mostra uma run que já acabou (a Run 1 do Classic), para o leitor conseguir ler os resultados finais. A sonda só lê: mostra as runs que o Top Shot dá como ativas e anota os pedidos que a página do Fast Break faz quando abres uma run e a classificação (nomes dos pedidos e ids de runs e dias). Endereços, nomes de utilizador e a tua autorização nunca saem da página.

No computador (melhor)

  1. Arrasta este botão para a barra dos favoritos: FB sonda runs
  2. Abre nbatopshot.com/fastbreak?league=nba com a tua conta.
  3. Carrega no favorito: a caixa diz “Já estou a anotar”.
  4. Abre a Run 1 do Classic e a classificação dela (e o último dia), como fazes para ver os resultados.
  5. Carrega em Copiar na caixa e cola no chat.

No telemóvel

Carrega em Copiar o código, edita um favorito e cola isto no endereço (URL). No Top Shot, escreve o nome do favorito na barra de endereço e escolhe-o. Os passos são os mesmos.
