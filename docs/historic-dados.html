Dados do Historic

Lê no Top Shot o que preciso para sugerir o lineup do Historic: as lendas de hoje com os Roster Points e os resultados simulados dos dias que já passaram. A tua sessão do Top Shot só é usada dentro do Top Shot; nada é enviado: tu é que copias e me mandas.

No computador

  1. Arrasta este botão para a barra dos favoritos: FB historic dados
  2. Abre nbatopshot.com com a tua conta e vai ao Fast Break.
  3. Carrega no favorito: aparece uma caixa laranja. Toca noutro separador do Fast Break para ela começar.
  4. Espera por “Feito” (uns segundos), carrega em Copiar e cola no chat.

No telemóvel

Carrega em Copiar o código, edita um favorito e cola isto no endereço (URL). No Top Shot, escreve o nome do favorito na barra de endereço e escolhe-o. Os passos são os mesmos.
