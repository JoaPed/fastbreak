FB lugares

Põe na Classificação do site o lugar de cada conta do grupo (smurfs incluídas) na run do Fast Break. Corre na página do Top Shot e usa a tua sessão de lá só para pedir os lugares ao próprio Top Shot; ao site só chegam os lugares.

Como se usa: no site, Grupo → Classificação → Atualizar lugares. Abre o Fast Break no Top Shot; aí toca no favorito FB lugares e depois uma vez em Leaderboard. Volta sozinho ao site com os lugares.

iPhone (Safari)

  1. Copia este texto (toca na caixa e escolhe Copiar):
  2. Toca em Partilhar → Adicionar marcador (qualquer página serve) e guarda-o com o nome FB lugares.
  3. Abre os marcadores, carrega em Editar, escolhe o «FB lugares» e substitui o endereço pelo texto copiado.

Sem tocar no favorito (opcional): instala a app gratuita Userscripts (App Store), ativa-a em Definições → Safari → Extensões, abre este script no Safari e instala-o pela extensão. A partir daí, ao vires do site, basta tocar em Leaderboard.

Computador

Mostra a barra dos favoritos (Ctrl+Shift+B) e arrasta este botão para lá: FB lugares. Com Tampermonkey, podes instalar o script em vez do favorito.
