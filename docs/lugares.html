FB lugares

Lê no Top Shot, para o site: o lugar de cada conta do grupo (smurfs incluídas) na run do Fast Break, os picks do dia, os preços do mercado (o Moment mais barato à venda de cada jogador, por escalão) e a raridade e o ASP das cartas do grupo. Corre na página do Top Shot e usa a tua sessão de lá só para pedir isto ao próprio Top Shot; ao site só chegam esses dados.

Novidade: o código agora é curto e vai buscar sempre a versão mais recente do script. Se já tinhas o «FB lugares», copia este código e cola-o no endereço do favorito outra vez (só esta vez).

Como se usa: é um só favorito para tudo. No site, em Ajustes → Admin → Ler no Top Shot, escolhes o que ler: Lugares e picks (rápido, todos os dias antes dos jogos), Preços dos jogadores ou Cartas (ASP) (1–2 minutos cada, de vez em quando). O botão abre o Fast Break no Top Shot e diz ao script o que ler; aí toca no favorito FB lugares e depois uma vez em Leaderboard. Volta sozinho ao site.

iPhone (Safari)

  1. Toca no botão para copiar o código:
    (se não der, toca na caixa → Selecionar tudo → Copiar)
  2. Toca em Partilhar → Adicionar marcador (qualquer página serve) e guarda-o com o nome FB lugares.
  3. Abre os marcadores, carrega em Editar, escolhe o «FB lugares» e substitui o endereço pelo texto copiado.

Sem tocar no favorito (opcional): instala a app gratuita Userscripts (App Store), ativa-a em Definições → Safari → Extensões, abre este script no Safari e instala-o pela extensão. A partir daí, ao vires do site, basta tocar em Leaderboard.

Computador

Mostra a barra dos favoritos (Ctrl+Shift+B) e arrasta este botão para lá: FB lugares. Com Tampermonkey, podes instalar o script em vez do favorito.
